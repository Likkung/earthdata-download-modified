# Contributing to Earthdata Download Modified

Modified October 16, 2026 for this independent, unofficial derivative.

## Who maintains this version?

This repository is maintained by **Likkung**. **OpenAI Codex** assisted with code development, focused automated tests, documentation and Windows/Linux packaging under Likkung's direction.

NASA's Earthdata Download team developed the original application. They do not review, approve or maintain changes in this repository. The upstream commit history and Apache-2.0 notices are retained as attribution.

## Making changes here

1. For people who have access to this private repository, create a branch and make your changes.
2. Describe the problem and resulting behavior, keeping the existing interface consistent.
3. Run the focused regression tests and build checks relevant to the change. State what has and has not been verified.
4. Open a pull request **in this repository**, for review by Likkung or an explicitly designated maintainer.

Use clear commit messages. A NASA EDSC ticket number is **not required** for this modified version.

## Proposing changes to NASA's original project

Only if you choose to submit a separate pull request to [nasa/earthdata-download](https://github.com/nasa/earthdata-download), follow [their upstream contribution guidelines](https://github.com/nasa/earthdata-download/blob/main/CONTRIBUTING.md). Those guidelines describe NASA's review process for submissions to their repository; they are not a requirement to develop or build this independent version.
